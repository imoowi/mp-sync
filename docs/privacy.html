公众号文章同步助手 隐私政策

生效日期：2026 年 11 月 18 日 · 适用版本：0.2.3 及以后

公众号文章同步助手（以下简称“本插件”）是一款 Microsoft Edge / Chromium 浏览器扩展，用于把用户本人有权使用的微信公众号文章， 在用户主动操作后保存为用户本人账号下的其他内容平台草稿。本政策说明本插件如何访问、使用、存储和传输数据。

核心说明：本插件没有开发者运营的数据服务器，不向开发者服务器上传、收集或出售用户数据，也不包含广告或第三方统计代码。 只有在用户点击“同步为草稿”并选择目标平台后，文章内容、图片和必要的登录状态才会发送到用户选择的平台。

一、我们处理哪些数据

数据类别具体内容用途存储位置
文章内容 标题、作者、摘要、正文、原文链接、图片地址、封面地址 在插件中展示、编辑，并在用户主动同步时保存到所选平台 浏览器本地存储
用户编辑内容 修改后的标题、摘要、Markdown / HTML 正文 保留用户编辑结果并用于同步 浏览器本地存储
同步记录与偏好 草稿 ID、草稿链接、同步时间、勾选的平台、面板状态、开源中国个人空间地址 再次同步时更新原草稿、打开草稿、记住用户选择 浏览器本地存储
平台登录状态 浏览器 Cookie 中的必要字段，以及美篇、即刻页面 localStorage 中的登录标记 判断用户是否已登录，并完成平台请求校验 只读取，不保存；登录探测结果最多在浏览器会话存储中缓存 5 分钟
标签页信息 当前文章页、已打开的登录页、临时编辑器页 读取文章、检测登录、打开和关闭同步所需页面 不持久化保存
图片数据 文章正文图片和封面图片 下载公众号图片并上传到用户所选平台自己的图床 不保存到开发者服务器；仅在同步过程中临时处理

关于登录凭证

  • 本插件不读取、不保存任何平台的账号密码，也不要求用户向插件输入密码。
  • 本插件复用用户浏览器中已经存在的登录状态。平台接口请求会携带浏览器自动管理的 Cookie。
  • 部分平台需要读取 Cookie 中的防伪字段或用户名，例如知乎 _xsrf、CSDN UserName、B 站 bili_jct、搜狐 mp-cv。
  • 美篇、即刻的登录状态存放在网页 localStorage 中。本插件只读取是否存在登录标记和昵称，不保存、不导出、不上传令牌本身。

二、我们如何使用数据

本插件只将上述数据用于以下与单一用途直接相关的操作：

  • 从当前微信公众号文章页提取文章内容和图片地址；
  • 在本地编辑器中预览、修改和保存文章；
  • 检查用户所选平台的登录状态；
  • 把文章、图片和封面保存为用户本人账号下的平台草稿；
  • 展示草稿链接和同步结果，便于用户检查后自行发布。

本插件不会将数据用于广告、用户画像、信用评估、内容推荐、出售或其他与同步草稿无关的用途。

三、数据会发送到哪里

只有在用户主动点击“同步为草稿”后，本插件才会把文章内容和图片发送到用户在界面中勾选的平台。 可能涉及的平台包括：

微信公众平台、掘金、CSDN、知乎、思否（SegmentFault）、开源中国、51CTO、小红书、今日头条、百家号、 简书、豆瓣、美篇、即刻、哔哩哔哩、搜狐号、雪球、人人都是产品经理、抖音。

图片可能上传到这些平台自己的图片存储服务，包括但不限于字节跳动 ImageX、七牛云、阿里云 OSS、又拍云、 B 站图床、搜狐图床、雪球图床、华为云 OBS 和腾讯云 COS。图片只会上传到用户所选同步平台对应的图床。

除上述用户主动选择的平台外，本插件不会把数据发送给开发者或其他第三方。各平台对数据的处理适用其各自的隐私政策。

四、数据存储与保留

  • 编辑中的文章、同步记录和偏好设置保存在浏览器本地存储中。
  • 用户卸载扩展或在浏览器扩展管理中清除本插件数据后，本地数据会被删除。
  • 登录探测缓存保存在浏览器会话存储中，浏览器关闭后失效。
  • 已经保存到各平台的草稿由对应平台保存和管理，用户应到对应平台删除或修改。

五、用户控制

  • 用户可以自行决定勾选哪些平台；不勾选时不会向该平台发送数据。
  • 用户可以随时停止使用同步功能；本插件不会在后台持续上传文章。
  • 用户可以卸载扩展，删除插件保存的本地文章、同步记录和偏好设置。
  • 用户可以在对应平台删除已经创建的草稿。

六、安全措施

  • 本插件只通过 HTTPS 访问平台接口和图床。
  • 本插件不加载或执行远程代码，所有运行代码均包含在扩展安装包内。
  • 本插件不保存账号密码，也不把 Cookie 导出到开发者服务器。
  • 由于各平台接口并非公开接口，平台改版可能导致同步暂时失败；用户应在发布前检查草稿内容。

七、Chrome Web Store 与 Microsoft Edge Add-ons 合规声明

本插件对用户数据的访问和使用，遵守 Chrome Web Store 用户数据政策（包括 Limited Use 要求）以及 Microsoft Edge Add-ons 开发者政策。数据仅用于实现本政策披露的单一用途，不用于个性化广告、出售、 数据经纪或其他无关目的。

Limited Use statement: The use of information received from browser APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

八、未成年人

本插件面向需要管理自身文章草稿的内容创作者，不面向儿童。我们不会有意收集儿童的个人信息。

九、政策更新

如果本插件的数据处理方式发生实质性变化，我们会更新本页面并修改生效日期。 用户应在本页面查看最新版本。继续使用更新后的插件，表示用户知悉更新后的数据处理方式。

English Summary

This extension helps users save articles they are authorized to use from WeChat Official Accounts as drafts in their own accounts on other content platforms. The extension has no developer-operated data server and does not sell user data, display ads, or include third-party analytics.

Article content, images, sync records, and preferences are processed locally. Existing browser cookies and, for Meipian and Jike, page localStorage login markers are read only to determine login status and to make user-initiated requests. Data is transmitted to a third-party platform only after the user selects that platform and clicks “sync as draft”.

The extension is not affiliated with Tencent, WeChat, Microsoft, Google, or any listed platform. For privacy questions or deletion requests, contact simpleyuan@gmail.com.

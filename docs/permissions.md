# 权限说明（提交商店审核用）

公众号文章同步助手 没有自己的服务器，所有数据只在用户浏览器本地处理；只有在用户点击「同步为草稿」后，才以**用户本人的登录身份**向用户选择的平台保存草稿。

以下文字可直接填入 Edge / Chrome 商店的「权限用途说明」。

## 权限（permissions）

| 权限 | 用途 |
|---|---|
| `activeTab` | 用户点击工具栏图标时，在当前公众号文章页打开或收起同步面板。 |
| `scripting` | 在公众号文章页读取文章标题、正文、图片和封面（`content/wechat.js`）；在开源中国、小红书的编辑器页面中填写并保存草稿（这两个平台只能在其页面内保存）。 |
| `storage` | 在本地保存用户编辑后的文章、同步记录（草稿 ID 和链接）、勾选的平台和面板状态。数据不离开浏览器。 |
| `cookies` | 读取各平台登录 Cookie 中的必要字段（如 CSDN 用户名、知乎 `_xsrf` 防伪令牌），用于判断是否已登录并通过平台的请求校验。不保存、不上传 Cookie。 |
| `tabs` | 打开「编辑文章」页和「打开草稿」链接；为开源中国临时打开编辑器标签页，保存后自动关闭；为小红书、今日头条、百家号、豆瓣、美篇、即刻打开编辑器标签页供用户检查。 |
| `clipboardWrite` | 在平台编辑器自动填充失败时，把文章正文复制到剪贴板，方便用户手动粘贴。只写入，不读取剪贴板。 |
| `declarativeNetRequestWithHostAccess` | 扩展后台发出的请求，其来源（Origin/Referer）是 `chrome-extension://`，部分平台会因此拒绝。本权限只把**扩展自己发出的请求**（tabId = -1）的来源改成对应平台自身的域名，不影响用户正常浏览的任何网页请求。同样用于下载公众号图片以便转存（公众号图片有防盗链）。 |

## 内容脚本（content_scripts）

只在 `https://mp.weixin.qq.com/s*`（公众号文章页）注入 `content/panel.js`，用于显示同步面板。不在其他任何网站注入脚本。

## 远程代码

本插件不加载、不执行任何远程代码，全部代码都包含在扩展包内。

## 单一用途说明（Single purpose）

把用户自己的微信公众号文章，经用户编辑后，以用户本人的身份保存为其他内容平台的草稿。
